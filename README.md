# Sports Match Pattern Analyzer

## Overview
A data analysis project designed to evaluate multi-week sports match results utilizing robust 2D array matrix operations. It processes historical data to identify statistical distributions, trends, and predictive patterns based on structural row and column analysis.

## Features
* **Matrix Data Processing:** Employs a comprehensive 2D array to map weeks (rows) against specific match slots (columns).
* **Row-Based Analysis:** Calculates weekly outcome distributions (Home Win, Draw, Away Win) to track periodic trends.
* **Column-Based Analysis:** Aggregates totals for specific match slots over 15+ weeks to identify persistent positional patterns.

## Technologies Used
* **Language:** Java
* **Concepts:** Data Structures (2D Arrays), Matrix Traversal, Statistical Aggregation, Pattern Recognition.

## How to Run
1. Compile the Java file: `javac MatchPatternAnalyzer.java`
2. Execute the compiled class: `java MatchPatternAnalyzer`
